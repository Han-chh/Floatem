# Floatem 1.1.0 (build 68) manual release checklist

Use an archived Release build for Agent and App Store checks. Use the Debug build only for the isolated developer-shortcut checks.

## Identity and startup

- [ ] Finder and About report version `1.1.0`; Finder reports build `68`.
- [ ] Direct launch shows the Main Window without adding Floatem to the Dock.
- [ ] The Floatem status icon remains visible on the right side of the menu bar.
- [ ] Login Item launch remains silent and restores desktop-pinned cards without opening the Main Window.

## Menu-bar and in-app recovery

- [ ] The status menu follows the selected app language.
- [ ] Its first item reads Hide Floatem while the panel is visible and Show Floatem while it is hidden.
- [ ] Reload Interface recreates the interface and reveals Floatem even when the panel was hidden.
- [ ] Quit closes Floatem normally.
- [ ] Right-clicking the Main Window and a floating card shows only the compact localized Quit Floatem menu, not the WebKit Reload/Inspect/Lookup menu.
- [ ] The Settings home Quit Floatem action still works.

## Global shortcut and Agent lifecycle

- [ ] An installed Release build responds to `Shift+Space` and reports a conflict when registration fails.
- [ ] Launching a newer Release build repairs a stale Agent registration that points to an older app path.
- [ ] Removing the containing app causes its Agent to release the shortcut and exit instead of showing a missing-application dialog.
- [ ] A Debug build registers no persistent Agent and responds only to `Option+Shift+Space`.
- [ ] Run Debug and Release together: `Option+Shift+Space` toggles only Debug, and `Shift+Space` toggles only Release.

## Notes and clipboard

- [ ] Focus a long Note body repeatedly with its toolbar expanded and collapsed; the toolbar does not jump.
- [ ] Copy mixed bold, italic, underline, and colored Note text into another compatible rich-text editor; supported formatting is preserved.
- [ ] Paste formatted text into Floatem while a different toolbar style is active; the pasted text keeps its source formatting.
- [ ] Plain-text clipboard fallback, clear formatting, undo, redo, and collapsed-toolbar persistence still work.

## Instructions and localization

- [ ] English and Simplified Chinese Instructions contain the same sections and current feature coverage.
- [ ] Instructions describe the menu-bar, Dock-free, reload, quit, rich-text, Notes, Todos, floating-card, settings, and shortcut workflows.
- [ ] Instructions contain no embedded release or build numbers.
- [ ] Debug Instructions display `Option+Shift+Space`; Release Instructions display the shortcut actually reported by the Agent.

## Release checks

- [x] Run the complete frontend test suite.
- [x] Build the production main and floating frontend bundles.
- [x] Run the complete macOS XCTest suite.
- [ ] Archive with Release configuration, validate code signing and App Group entitlements, and upload build 68 through Xcode.
