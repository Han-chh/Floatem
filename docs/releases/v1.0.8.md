## Product behavior

Floatem is a local-first macOS desktop notes and todos app built to capture ideas without interrupting the current task.

- Create, edit, reorder, group, color, filter, collapse, and rich-format notes.
- Create dated todos, organize them into groups, filter them, complete/reopen them, and attach reminders.
- Summon or hide Floatem using the global shortcut (`Shift+Space` by default) or menu-bar controls.
- Drag Notes and Todos into editable floating cards, resize them, keep them above ordinary work, and drag them back.
- Pin app-owned cards at the desktop window level. Floatem must remain running; enabling **Open Floatem at login** silently restores saved desktop cards after login.
- Choose English or Simplified Chinese, six themes, three transition styles/speeds, time zone/format, particle feedback, reminder sound, shortcut behavior, and the default opening section.
- Open bilingual feature help or start a seven-workflow interactive guide that uses temporary practice data and restores the user's prior UI state.
- Keep Notes, Todos, settings, floating placement, and desktop-panel state locally in the App Group container. v1.0.8 has no account, telemetry, or cloud-sync feature.

## v1.0.8 change

On a fresh installation, the upper-right help button now receives a focused animated highlight and a bilingual callout asking the user to open the feature help/interactive guide. The user can open the guide or dismiss the callout for later. The acknowledgement is persisted locally and is not reintroduced for existing users upgrading from an older settings document.

The first-install help hint owns the first-session onboarding surface so it does not collide with the launch-at-login explanation. The launch-at-login prompt may appear on a later direct-launch session while launch at login remains disabled and the user has not suppressed that prompt.
