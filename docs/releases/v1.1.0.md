## User-facing changes

- Floatem now runs as a menu-bar accessory and never appears in the Dock.
- The bilingual menu-bar menu changes between Show Floatem and Hide Floatem according to the Main Window state. It can also reload and reveal the interface or quit the app.
- Right-clicking the Main Window or a floating card opens a compact, localized Floatem menu with a Quit action instead of WebKit's unrelated default menu.
- Copying Note text preserves supported bold, italic, underline, and text-color formatting. Pasting keeps the source formatting instead of inheriting the toolbar's current typing style.
- Focusing a long Note body no longer causes the attached formatting toolbar to jump.
- The in-app Instructions now describe the current Notes, Todos, floating-card, menu-bar, settings, shortcut, recovery, and quit workflows in aligned English and Simplified Chinese without embedding release-specific version information.

## Shortcut and lifecycle reliability

- The Release shortcut Agent validates its containing app before handling the global shortcut. If Floatem has been removed, the Agent releases the shortcut and exits.
- Floatem verifies that the registered Agent belongs to the current installation, repairs stale registrations, uses a bounded startup handshake, and shows a localized conflict warning when registration still fails.
- Daily Debug builds do not register a persistent Agent. They use a process-local `Option+Shift+Space` shortcut so Debug and installed Release builds can run side by side.
