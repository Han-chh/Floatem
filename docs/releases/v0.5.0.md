# StickIt v0.5.0 Release Notes

## 1. Overview

StickIt v0.5.0 introduces floating notes and floating todos on macOS. Notes and todos can be detached from the main panel into native always-on-top floating cards, edited in place, moved around the screen, and docked back into the main panel.

Windows floating notes and floating todos are not supported in v0.5.0. The Windows floating implementation from the mixed development branch was intentionally excluded due to rendering/composition instability.

## 2. New on macOS

- Added native macOS floating card infrastructure.
- Added drag previews while pulling notes and todos out of the main panel.
- Added native floating-card windows for notes and todos.
- Added dock-zone feedback when a floating card is dragged back over the StickIt panel.
- Added frontend state synchronization so docked lists hide items while they are floating.

## 3. Floating Notes

- Drag a note card away from the main Notes list to create a floating note card.
- Edit note title, body, formatting, group, color, and collapsed state from the floating card.
- Drag the floating note card around the screen.
- Drag it back onto the StickIt panel or close it to dock it back into the Notes list.

## 4. Floating Todos

- Drag an open todo away from the Todos list to create a floating todo card.
- Edit todo text, date, group, reminder, and completion state from the floating card.
- Completing a floating todo saves it and docks the floating card after a short delay.
- Drag the floating todo card back onto the StickIt panel or close it to dock it back into the Todos list.

## 5. Windows Support Status

Windows floating notes and floating todos are not supported in v0.5.0.

Floating Notes & Todos are currently supported on macOS only. They are disabled on Windows in v0.5.0 due to rendering/composition instability. Windows keeps the stable v0.4.5 notes/todos behavior, and user data remains compatible with the regular Notes and Todos panels.

Future Windows floating support should be developed separately from a clean architecture branch. It will require a separate architecture redesign rather than carrying forward the unstable mixed-branch implementation.

## 6. Known Limitations

- Floating cards are macOS-only in v0.5.0.
- Browser preview cannot create native floating card windows.
- Windows floating controls are disabled or hidden in v0.5.0.
- Windows users should continue using the regular Notes and Todos panels.

## 7. Upgrade Notes

- Existing notes, todos, settings, groups, reminders, and local data remain compatible.
- macOS users can start using floating cards after upgrading to v0.5.0.
- Windows users keep the stable v0.4.5 floating-related behavior, with no new Windows floating functionality enabled.

## 8. Developer Notes

- The release branch was created from the v0.4.5 baseline.
- The mixed macOS + Windows floating development state is preserved separately for research/history.
- macOS floating implementation was selectively extracted from the preserved mixed branch.
- Windows host floating implementation files were intentionally excluded.
- Shared frontend floating code is guarded by platform feature flags:
  - macOS: floating notes enabled, floating todos enabled.
  - Windows: floating notes disabled, floating todos disabled.
