# Floatem v1.0.10 (build 51) manual release checklist

Use the installed signed Release build at `/Applications/Floatem.app`.

## Identity and startup

- [ ] Finder and About report version `1.0.10`; Finder reports build `51`.
- [ ] Direct launch opens the Main Window; Login Item launch remains silent.
- [ ] Notes, Todos, settings, reminders, and desktop placement survive relaunch.

## Desktop-pinned regression

- [ ] Drag a compact Todo out of Floatem and pin it to the desktop.
- [ ] Verify only the circular pin indicator turns black; its outer rounded button keeps the ordinary border and background.
- [ ] Verify pin, group, reminder, and close controls are fully visible and clickable.
- [ ] Quit Floatem completely, relaunch it, and verify the same Todo returns at its saved size and placement with all four controls visible and functional.
- [ ] Repeat the relaunch check with a resized Todo, a Note, a second display, and a changed display scale.
- [ ] Unpin the restored card and verify it returns to ordinary floating overlay behavior.
