# Quicknote Platform Support

| Feature | macOS | Windows |
| --- | --- | --- |
| Notes | Supported | Supported |
| Todos | Supported | Supported |
| Floating Notes | Supported in v0.5.0 | Not supported in v0.5.0 |
| Floating Todos | Supported in v0.5.0 | Not supported in v0.5.0 |

Floating Notes & Todos are currently supported on macOS only. They are disabled on Windows in v0.5.0 due to rendering/composition instability. Windows keeps the stable v0.4.5 notes/todos behavior.
